# Политика конфиденциальности «Чистого поиска»

_Дата: 22.10.2026_

## Какие данные обрабатываются

- **Страницы результатов поиска** Google, Bing и DuckDuckGo. Расширение читает их структуру прямо в браузере, чтобы найти блоки и ссылки, которые нужно скрыть. Поисковые запросы и результаты никуда не сохраняются и не передаются.
- **Настройки:** какие блоки скрывать, режим «только веб», выбранные поисковые системы и адрес обновления правил, если вы его указали.
- **Чёрный список сайтов**, который вы составили.
- **Загруженные правила**, если вы включили их обновление по сети.

## Где хранятся данные

Все данные хранятся только локально, в `chrome.storage.local` вашего браузера. Они не синхронизируются и не передаются ни автору, ни третьим лицам.

## Сетевые запросы

По умолчанию расширение не делает никаких сетевых запросов.

Если вы сами включите «Обновлять правила из JSON по адресу», расширение раз в сутки, а также по кнопке «Проверить сейчас», скачивает файл с указанного вами HTTPS-адреса:

- запрос идёт без cookies, а в нём нет ваших данных, запросов или списка сайтов;
- в ответ принимаются только данные (JSON), которые проверяются по схеме;
- код из сети не загружается и не выполняется.

Режим «только веб» не делает своих запросов. Он лишь добавляет `udm=14` к адресу поиска Google, который вы открываете сами.

После установки расширение один раз открывает вкладку с короткой инструкцией на сайте автора, а после удаления браузер открывает страницу с вопросом «почему удалили?». Это обычные статические страницы: расширение не добавляет к их адресам никаких данных или идентификаторов и ничего им не передаёт.

## Чего расширение не делает

- Нет аналитики, телеметрии, рекламы и учётных записей.
- Нет доступа к сайтам, кроме страниц выдачи Google, Bing и DuckDuckGo.
- Не выполняется удалённый код.

## Удаление данных

Очистите чёрный список на странице настроек или просто удалите расширение — все данные будут удалены вместе с ним.
