Privacy Policy — Video Declutter

Date: 26.10.2026

What data is processed

  • YouTube pages (www.youtube.com). The extension reads their structure right in the browser in order to hide the parts you selected, redirect Shorts and turn off autoplay. What you watch and search for is not saved or transmitted anywhere.
  • Settings: which items to hide, the mode, the focus schedule, the reminder, whether rule updates are enabled.
  • Rule state: for each rule, when it last fired and how many times in a row it found no target. These are timestamps only, without page addresses.
  • Today's time counter (a single number of seconds and a date). It is reset at midnight.
  • Downloaded rules, if you have enabled rule updates.

Where the data is stored

Only locally, in your browser's chrome.storage.local. Nothing is synchronised and nothing is transmitted to the author or to third parties.

Network requests

By default the extension makes no network requests at all.

If you turn on "Update rules from the author's site", the extension once a day (and on the "Check now" button) downloads a single file, rules/youtube-clean/selectors.signed.json, from the author's site:

  • the request is sent without cookies and contains none of your data, settings or history;
  • only a file with data (CSS selectors) is accepted, signed with the author's key and validated against a schema;
  • no code is loaded or executed from the network.

The extension does not block or modify YouTube's network requests.

After installation the extension opens a tab with a short guide on the author's site once, and after removal the browser opens a "why did you uninstall?" page. These are ordinary static pages: the extension adds no data or identifiers to their addresses and transmits nothing to them.

What the extension does not do

  • No analytics, telemetry, advertising or accounts.
  • No access to any sites other than www.youtube.com.
  • No remote code is executed.

Deleting data

"Reset settings" on the settings page deletes the settings, the rule state and the downloaded rules. When the extension is removed, the browser deletes all of its data.

Contact

Questions can be asked through the issues of the project's repository on GitHub.

Политика конфиденциальности «Видео без мусора»

Дата: 26.10.2026

Какие данные обрабатываются

  • Страницы YouTube (www.youtube.com). Расширение читает их структуру прямо в браузере, чтобы скрыть выбранные части, перенаправить Shorts и выключить автовоспроизведение. Что вы смотрите и ищете, никуда не сохраняется и не передаётся.
  • Настройки: какие пункты скрывать, режим, расписание фокуса, напоминание, включено ли обновление правил.
  • Состояние правил: для каждого правила — когда оно последний раз сработало и сколько раз подряд не нашло цель. Это только отметки времени, без адресов страниц.
  • Счётчик времени за сегодня (одно число секунд и дата). Сбрасывается в полночь.
  • Скачанные правила, если вы включили их обновление.

Где хранятся данные

Только локально, в chrome.storage.local вашего браузера. Ничего не синхронизируется и не передаётся ни автору, ни третьим лицам.

Сетевые запросы

По умолчанию расширение не делает никаких сетевых запросов.

Если вы включите «Обновлять правила с сайта автора», расширение раз в сутки (и по кнопке «Проверить сейчас») скачивает один файл rules/youtube-clean/selectors.signed.json с сайта автора:

  • запрос идёт без cookies и не содержит ваших данных, настроек или истории;
  • принимается только файл с данными (селекторы CSS), подписанный ключом автора и проверенный по схеме;
  • код из сети не загружается и не выполняется.

Расширение не блокирует и не изменяет сетевые запросы YouTube.

После установки расширение один раз открывает вкладку с короткой инструкцией на сайте автора, а после удаления браузер открывает страницу с вопросом «почему удалили?». Это обычные статические страницы: расширение не добавляет к их адресам никаких данных или идентификаторов и ничего им не передаёт.

Чего расширение не делает

  • Нет аналитики, телеметрии, рекламы и учётных записей.
  • Нет доступа к сайтам, кроме www.youtube.com.
  • Не выполняется удалённый код.

Удаление данных

«Сбросить настройки» на странице настроек удаляет настройки, состояние правил и скачанные правила. При удалении расширения браузер удаляет все его данные.

Контакты

Вопросы можно задать через issues репозитория проекта на GitHub.
