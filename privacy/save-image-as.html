Privacy Policy — Save Picture As…

Date: 26.10.2026

What data is processed

  • The image you selected in the context menu. The extension receives it only after you click the menu item: it reads it from the page (through temporary activeTab access to that tab) or downloads it from the image's address if you have allowed access to that server. The image is converted to PNG, JPG or WebP right in the browser and saved to the downloads folder (or copied to the clipboard). The extension keeps no copy.
  • The image address, its description (alt) and the page title — only to compose the file name. They are not saved anywhere.
  • Settings (default format, quality, background colour, name pattern, etc.) are stored in chrome.storage.local.
  • While a site-access request is open, information about the unfinished save (image address, tab) is kept in chrome.storage.session — this is browser memory, cleared when the browser is closed.

Where the data goes

Nowhere. The extension has no server. The only network requests are the download of the image itself from its own address, as the browser does when it displays the page. Nothing is transmitted to us or to third parties.

Site access

At installation the extension gets no access to any sites. If an image lives on another server and cannot be read from the page, the extension asks for permission for that particular server (or, if you decide so, for all sites). The permission is used only to download images that you selected in the menu. The list of granted permissions and "Remove" buttons are in the extension's settings.

What the extension does not do

  • It collects no statistics, shows no advertising and requires no account.
  • It does not read pages in the background and does not embed anything into sites in advance: code runs on a tab only after your click.
  • It does not load or execute remote code.

The author's site pages

After installation the extension opens a tab with a short guide on the author's site once, and after removal the browser opens a "why did you uninstall?" page. These are ordinary static pages: the extension adds no data or identifiers to their addresses and transmits nothing to them.

Deleting data

Press "Reset settings" on the settings page or simply remove the extension — the settings and permissions are removed along with it.

Contact

Questions can be asked through the issues of the project's repository on GitHub.

Политика конфиденциальности «Сохранить картинку как…»

Дата: 26.10.2026

Какие данные обрабатываются

  • Картинка, которую вы выбрали в контекстном меню. Расширение получает её только после вашего клика по пункту меню: читает со страницы (через временный доступ activeTab к этой вкладке) или скачивает с адреса картинки, если вы разрешили доступ к этому серверу. Картинка конвертируется в PNG, JPG или WebP прямо в браузере и сохраняется в папку загрузок (или копируется в буфер обмена). Копии у расширения не остаётся.
  • Адрес картинки, её описание (alt) и заголовок страницы — только чтобы составить имя файла. Нигде не сохраняются.
  • Настройки (формат по умолчанию, качество, цвет фона, шаблон имени и т. п.) хранятся в chrome.storage.local.
  • Пока открыт запрос доступа к сайту, сведения о незавершённом сохранении (адрес картинки, вкладка) лежат в chrome.storage.session — это память браузера, она очищается при его закрытии.

Куда уходят данные

Никуда. У расширения нет сервера. Единственные сетевые запросы — загрузка самой картинки с её собственного адреса, как это делает браузер при показе страницы. Ничего не передаётся ни нам, ни третьим лицам.

Доступ к сайтам

При установке расширение не получает доступа к сайтам. Если картинка лежит на другом сервере и прочитать её со страницы нельзя, расширение спрашивает разрешение именно для этого сервера (или, если вы так решите, для всех сайтов). Разрешение используется только для скачивания картинок, которые вы выбрали в меню. Список выданных разрешений и кнопки «Убрать» есть в настройках расширения.

Что расширение не делает

  • Не собирает статистику, не показывает рекламу, не требует учётной записи.
  • Не читает страницы в фоне и ничего не встраивает в сайты заранее: код выполняется на вкладке только после вашего клика.
  • Не загружает и не выполняет удалённый код.

Страницы сайта автора

После установки расширение один раз открывает вкладку с короткой инструкцией на сайте автора, а после удаления браузер открывает страницу с вопросом «почему удалили?». Это обычные статические страницы: расширение не добавляет к их адресам никаких данных или идентификаторов и ничего им не передаёт.

Удаление данных

Нажмите «Сбросить настройки» на странице настроек или просто удалите расширение — вместе с ним удалятся настройки и разрешения.

Контакты

Вопросы можно задать через issues репозитория проекта на GitHub.
