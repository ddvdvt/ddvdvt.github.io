Privacy Policy — Clean Search

Date: 22.10.2026

What data is processed

  • Search results pages of Google, Bing and DuckDuckGo. The extension reads their structure right in the browser to find the blocks and links that need to be hidden. Search queries and results are not saved or transmitted anywhere.
  • Settings: which blocks to hide, the "web only" mode, the chosen search engines and the rules update address, if you specified one.
  • The site blocklist that you compiled.
  • Downloaded rules, if you turned on their update over the network.

Where the data is stored

All data is stored only locally, in your browser's chrome.storage.local. It is not synchronised and is not transmitted to the author or to third parties.

Network requests

By default the extension makes no network requests at all.

If you yourself turn on "Update rules from JSON at an address", the extension once a day, and also on the "Check now" button, downloads a file from the HTTPS address you specified:

  • the request is sent without cookies and contains none of your data, queries or list of sites;
  • only data (JSON) is accepted in response, and it is validated against a schema;
  • no code is loaded or executed from the network.

The "web only" mode makes no requests of its own. It only adds udm=14 to the Google search address that you open yourself.

After installation the extension opens a tab with a short guide on the author's site once, and after removal the browser opens a "why did you uninstall?" page. These are ordinary static pages: the extension adds no data or identifiers to their addresses and transmits nothing to them.

What the extension does not do

  • No analytics, telemetry, advertising or accounts.
  • No access to sites other than the results pages of Google, Bing and DuckDuckGo.
  • No remote code is executed.

Deleting data

Clear the blocklist on the settings page or simply remove the extension — all data will be deleted along with it.

Contact

Questions can be asked through the issues of the project's repository on GitHub.

Политика конфиденциальности «Чистого поиска»

Дата: 22.10.2026

Какие данные обрабатываются

  • Страницы результатов поиска Google, Bing и DuckDuckGo. Расширение читает их структуру прямо в браузере, чтобы найти блоки и ссылки, которые нужно скрыть. Поисковые запросы и результаты никуда не сохраняются и не передаются.
  • Настройки: какие блоки скрывать, режим «только веб», выбранные поисковые системы и адрес обновления правил, если вы его указали.
  • Чёрный список сайтов, который вы составили.
  • Загруженные правила, если вы включили их обновление по сети.

Где хранятся данные

Все данные хранятся только локально, в chrome.storage.local вашего браузера. Они не синхронизируются и не передаются ни автору, ни третьим лицам.

Сетевые запросы

По умолчанию расширение не делает никаких сетевых запросов.

Если вы сами включите «Обновлять правила из JSON по адресу», расширение раз в сутки, а также по кнопке «Проверить сейчас», скачивает файл с указанного вами HTTPS-адреса:

  • запрос идёт без cookies, а в нём нет ваших данных, запросов или списка сайтов;
  • в ответ принимаются только данные (JSON), которые проверяются по схеме;
  • код из сети не загружается и не выполняется.

Режим «только веб» не делает своих запросов. Он лишь добавляет udm=14 к адресу поиска Google, который вы открываете сами.

После установки расширение один раз открывает вкладку с короткой инструкцией на сайте автора, а после удаления браузер открывает страницу с вопросом «почему удалили?». Это обычные статические страницы: расширение не добавляет к их адресам никаких данных или идентификаторов и ничего им не передаёт.

Чего расширение не делает

  • Нет аналитики, телеметрии, рекламы и учётных записей.
  • Нет доступа к сайтам, кроме страниц выдачи Google, Bing и DuckDuckGo.
  • Не выполняется удалённый код.

Удаление данных

Очистите чёрный список на странице настроек или просто удалите расширение — все данные будут удалены вместе с ним.

Контакты

Вопросы можно задать через issues репозитория проекта на GitHub.
